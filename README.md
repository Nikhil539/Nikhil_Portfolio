# Nikhil Reddy Portfolio

A dependency-free, responsive portfolio site built with semantic HTML, CSS, and JavaScript. This stack is intentionally lightweight: it loads quickly, is simple to maintain, and deploys to GitHub Pages, Netlify, or Vercel without a build step.

## Run locally

Open `index.html` directly in a browser, or serve the directory:

```powershell
cd nikhil-reddy-portfolio
npx serve .
```

## Deploy

### GitHub Pages

1. Push this folder to a repository.
2. In GitHub, open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main`, and choose `/(root)`.
4. Save. GitHub will provide the live URL.

### Netlify or Vercel

Import the repository, use the project root as the publish directory, and leave the build command empty. No environment variables are required.
